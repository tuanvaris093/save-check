# ตรวจและลดขนาดปุ่ม (D28)

วันที่: 15 ตุลาคม 2026 · ยังไม่ deploy

สาเหตุหลัก: .btn-primary-gradient และ .btn-secondary-glass ใน CSS กลางบังคับ height 52px จึงทับขนาด Tailwind ของ Button ทุก size รวมปุ่มล้างตัวกรองที่ตั้ง sm ไว้

## ผลการปรับ

| ส่วน | ขนาดใหม่ |
| --- | --- |
| Button ปกติ | 40px |
| Button ขนาดเล็ก | 32px |
| Button ขนาดใหญ่ | 44px |
| Button ไอคอน | 40 × 40px |
| เมนูล่าง | สูง 60px กว้างสูงสุด 320px |
| พื้นที่กดแต่ละเมนูล่าง | สูง 48px, ไอคอน 20px |

- เอาความสูงบังคับใน CSS ตกแต่งปุ่มออก ให้ขนาดแต่ละ size ทำงานจริง ลดมุมโค้ง/เงาปุ่มตามสัดส่วน
- ปุ่มล้างตัวกรองใช้ sm จริงและชิดขวา ไม่ขยายเต็มพื้นที่บนจอใหญ่
- ลดปุ่มทั่วไปที่ใช้ component ร่วมกัน ได้แก่ ถัดไป/ย้อนกลับ/ส่ง/เอกสาร/ประวัติ/ส่งออก
- ลดแท็บก่อน/หลังและปุ่มเลือกแหล่งเสียงให้กระชับ โดยข้อความยาวยังตัดบรรทัดและขยายความสูงได้
- ปรับ action links ในหน้าผล/complete/not-found ให้เข้าชุด และลด safe-area padding ตามความสูงเมนูล่างใหม่
- ไม่ย่อการ์ดเลือกฟอร์ม ช่องกรอก หรือปุ่มให้คะแนนแบบสอบถามจนอ่าน/เลือกยาก

- P7 browser 14 scenarios ผ่าน เพิ่มตรวจขนาดจริงของปุ่มล้าง <=34px/กว้าง <140px และเมนูล่าง <=320×60px พื้นที่กดแต่ละเมนู 44–50px ไม่มี document overflow ที่ 320/390/1440px
- P4 browser 10 scenarios ผ่าน พร้อมแท็บ/การ์ดคำถาม/เมนู fixed และส่งฟอร์ม/ต่อเนื่อง loading
