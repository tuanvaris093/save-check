# ปรับสัดส่วนปุ่มและ layout ตามภาพล่าสุด (D29)

วันที่: 15 ตุลาคม 2026 · done · ยังไม่ deploy

ตรวจหน้า localhost:3001 ที่เจ้าของงานใช้งานจริง พบปุ่มล้าง data-button-size=sm แต่ computed height ยังเป็น 52px จาก .btn-secondary-glass ใน stylesheet ที่ dev server ส่งอยู่ แม้ source CSS เดิมถูกแก้แล้ว จึงเพิ่ม compact-controls.css ที่ root layout และกำหนด selector ตาม data-button-size ให้มีลำดับความสำคัญสูงกว่า style ตกแต่ง ไม่ต้องหยุด server ของเจ้าของงาน

## สัดส่วนปัจจุบัน (แทนตัวเลข D28)

- ปุ่มปกติขั้นต่ำ 38px, เล็ก 30px, ใหญ่ขั้นต่ำ 42px, icon 38px; ใช้ height:auto ให้ข้อความยาวขยายได้
- ปุ่มล้างและปุ่มแบ่งหน้าใช้ small 30px เหมือนกัน มุม 8px/ตัวอักษร 12px
- จำนวนต่อหน้า select สูง 30px ตรงกับปุ่ม; pagination ชิดขอบแบบกระชับบน desktop และจัดกึ่งกลางเป็นกลุ่มบนมือถือ
- วันเริ่ม–สิ้นสุดจัดเป็นคู่ในแถวเดียว ไม่แยกคนละแถวบนมือถือ; ปุ่มล้างชิดขวา
- เมนูล่างกว้างสูงสุด 280px สูง 54px, พื้นที่กดแต่ละเมนูสูง 44px ไอคอน 18px และลดเงาให้สมดุล

## หลักฐาน
