# ส่งออกประวัติทุกรอบของงาน

15 ตุลาคม 2026 — D36

เพิ่มปุ่ม **ดาวน์โหลดประวัติทุกรอบ Excel** ในส่วนประวัติรอบตรวจของหน้าผลสภาพแวดล้อม ปุ่มดาวน์โหลด Excel เดิมยังส่งออกรอบที่กำลังเปิดอยู่ และ Dashboard ยังส่งออกผลล่าสุดตามตัวกรอง

## รูปแบบ

- ใช้แถวในชีตเดียวต่อประเภท/หมวด ชีตภาพรวมแสดงหนึ่งแถวต่อรอบ เรียงรอบเก่าไปใหม่ พร้อมครั้งที่บันทึก วันเวลาตรวจ วันเวลาบันทึก และล่าสุด/ย้อนหลัง
- ชีตฟอร์มรวมรายละเอียดครบทุกจุดของทุกรอบ หากมีจุดย่อย Area หรือช่วงวัด Heat จะมีหลายแถวต่อรอบ โดยทุกแถวมีเลขรอบและรหัสจุดเชื่อมโยง
- เก็บเกณฑ์ ค่าตรวจ ผล และวันเวลาของรอบเดิมตาม snapshot; ค่า carried มีวันวัดจริงและรหัสรอบต้นทางแยกจากวันตรวจรอบใหม่
- จำกัด query ด้วย submission_code ของงานที่เปิดอยู่, revision_scope=history อ่านครบทุกหน้าผ่าน bulk collector เดิม ตรวจไม่ให้มีข้อมูลต่างรหัสปน และไม่ดาวน์โหลดไฟล์บางส่วนเมื่อเกิดข้อผิดพลาด
- แสดงสถานะขณะอ่านประวัติ/สำเร็จ ปิดปุ่มส่งออกระหว่างทำงาน และลองใหม่ได้เมื่อไม่สำเร็จ
- ไม่เปลี่ยนฐานข้อมูลและไม่ deploy

## ตรวจสอบ

- Unit ตรวจ overview และชีตฟอร์มใน scope history มีทุกรอบเรียงลำดับ (1/12) ต่างจาก selected/latest
- Browser กดปุ่มจริงกับงาน 13 รอบ ตรวจภาพรวม 13 แถว เลขรอบ 1–13 ไม่ซ้ำ/ไม่ปนงานอื่น ล่าสุดมีรอบเดียว และค่าที่ไม่ผ่านของรอบแรกยังเป็นค่าเดิม
- ภาพและไฟล์ทดสอบ: `baseline/history-export.png`, `baseline/classic-job-history.xlsx`
- ผล: unit 11 + P7 browser 15 ผ่าน; typecheck, scoped ESLint, diff check ผ่าน ตรวจ render แถวประวัติด้วย artifact-tool

## D55 — ผู้ตรวจและข้อมูลประจำรอบ (16 ตุลาคม 2026)

- Excel ประวัติต้องอ่าน inspection snapshot ของแต่ละรอบ รวมชื่อผู้ตรวจ ตำแหน่ง สถานที่ เครื่องมือ Serial วันที่สอบเทียบ แผนกและผู้รับผิดชอบ ไม่ใช้ข้อมูลของรอบล่าสุดแทนรอบเก่า
- แสดงวันเวลาตรวจ วันเวลาบันทึกของแต่ละรอบ และวันสร้างงานเดิมแยกกัน วันที่ใน Excel ใช้เวลาไทย ค่าที่คงมาจากรอบก่อนยังแสดงวันเวลาวัดจริงเดิมและที่มาของค่า
- ชีตภาพรวมมีผู้ตรวจหนึ่งแถวต่อรอบ ชีตตามประเภท/หมวดมีข้อมูลครบทุกจุดพร้อมเลขรอบ และเก็บ snapshot เต็มของทุกรอบสำหรับตรวจสอบข้อมูลที่ไม่ได้แสดงเป็นคอลัมน์
- เพิ่ม browser regression ดาวน์โหลดไฟล์ก่อนตรวจซ้ำ และหลังตรวจจริง 3 รอบโดยผู้ตรวจต่างกัน ตรวจ metadata/วันเวลา/ค่าตรวจ/ผล/ที่มาของค่าทุกแถว เทียบข้อมูลรอบแรกก่อนและหลังตรงกัน ยกเว้นป้ายล่าสุดเปลี่ยนเป็นย้อนหลัง พร้อมตรวจ snapshot เต็มตรงกับ API ทั้ง 3 รอบ
- ไฟล์จากฐานข้อมูลทดสอบแยก: `baseline/retest-history-three-inspectors.xlsx`
