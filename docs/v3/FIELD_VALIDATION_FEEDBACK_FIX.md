# แก้ข้อความ validation ค้างหลังกรอกข้อมูล

วันที่: 15 ตุลาคม 2026 — ยังไม่ deploy

คำขอ: เมื่อกรอกหรือเลือกคำตอบแล้วให้ error ของช่องนั้นหายทันทีทั้งโปรเจ็ค

## การปรับ

- ฟอร์มสุขภาพทั้งสามหมวด, ข้อมูลส่วนตัว, ข้อมูลการเรียน/ทำงาน และชั่วโมงวันนี้ ล้าง error เฉพาะช่องที่มีการแก้ไข รวม radio และปุ่มเลือกแหล่งเสียง
- ฟอร์มสภาพแวดล้อม ล้าง error ตามชื่อช่อง metadata/ค่าตรวจ/จุด/ตัวอย่าง/ช่วงเวลา/เหตุผล ไม่ล้าง error ของจุดอื่น
- ฟอร์มความพึงพอใจ ล้าง error ชื่อ/ประเภทผู้ตอบ/หลักสูตร/ชั้นปี/ระยะเวลาทั้งสองวิธี/เหตุผล; คำถามคะแนนและส่วนฟอร์มที่ใช้ React Hook Form ตรวจเมื่อเปลี่ยนค่า
- ล้าง error ของข้อมูลเงื่อนไขที่เปลี่ยนตามประเภทผู้ตอบ/โรค/แหล่งเสียง และล้างข้อความสรุป validation เมื่อไม่มี error ช่องใดเหลือ
- เหตุผลเก็บเข้าคลังล้างข้อความบังคับกรอกเมื่อแก้ไข
- การแก้ช่องไม่ได้ยกเลิก validation: ยังคงตรวจ schema ทั้งชุดเมื่อกดถัดไป/บันทึก และ Worker ตรวจข้อมูลก่อนเขียนเช่นเดิม ข้อผิดพลาดเครือข่าย/ข้อขัดแย้งยังคงแสดงตามจริง

## ทดสอบ

- Health pending: 11 scenarios ผ่าน
- P5 browser: 16 scenarios ผ่าน เพิ่มตรวจว่าแก้ชื่อผู้ตรวจแล้ว aria-invalid หาย แต่ตำแหน่งที่ยังว่างยังมี error
- P6 browser: 11 scenarios ผ่าน เพิ่มตรวจชื่อผู้ตอบหายจาก error ทันที
- P4 browser 9 / P3 browser 11 scenarios ผ่าน เพิ่มตรวจ error คำถามสุขภาพ 10 → 9 → 0 เมื่อเลือกทีละข้อ โดยไม่กดส่งซ้ำ
- Frontend typecheck ผ่าน; lint 0 errors / 74 warnings เดิม; git diff --check ผ่าน

ขอบเขต browser: Chromium บน localhost กับ Worker/D1 ชั่วคราว ไม่มี deploy หรือแก้ฐานข้อมูล remote


## เพิ่มเติม: คะแนนความพึงพอใจยังติดแดง (15 ตุลาคม)

เจ้าของงานพบกรอบแดงและข้อความ “กรุณาให้คะแนน 1–5” ค้างที่ข้อ 6 แม้กดคะแนนแล้ว จึงเพิ่มการล้าง error ของ field โดยตรงใน onChange ของคะแนน และเมื่อคลิก radio ที่เลือกอยู่ซ้ำ โดยคง handler ของ React Hook Form และการตรวจ schema เดิม ไม่ล้าง error ข้ออื่น

ใช้สถานะ aria-invalid ที่ radiogroup ให้ตรงกับ error ของข้อ และเพิ่ม browser assertions: ส่งว่างแล้วมี 16 errors → เลือกข้อ 6 ได้คะแนน 5 จริง error เหลือ 15 → คลิกคะแนนเดิม error ไม่กลับมา → ตอบครบไม่มีข้อความ error โดยไม่กดส่งซ้ำ
