## 3. สรุปความเข้าใจ

หน้าแรกเหลือ 2 งานหลัก: **ประเมินสภาพแวดล้อมในการทำงาน** และ **ประเมินอาการทางสุขภาพ** แต่ละงานมี 4 เมนูย่อย ได้แก่ แสง เสียง ความร้อน และความพึงพอใจในการใช้แอปของงานนั้น โดยคงแนวทางหน้าตาเดิมและใช้ภาพใน Word เป็นตัวอย่างลำดับการใช้งาน

การเปลี่ยนที่กระทบโครงสร้างมากที่สุดมี 3 ส่วน: คำตอบสุขภาพด้านแสงต้องมีคู่ก่อน–หลัง, ความพึงพอใจต้องรู้ว่ามาจากกลุ่มงานใด, และการตรวจซ้ำต้องเป็นประวัติถาวรภายใต้รหัสงานเดิม ไม่ใช่การบันทึกทับ คำว่า temp ในเอกสารจึงตีความเป็น revision ที่เปิดย้อนหลังได้ ไม่ใช่ข้อมูลชั่วคราวที่ลบทิ้ง

**หมายเหตุจากลูกค้า:** กลุ่มสภาพแวดล้อม 46 คน และกลุ่มสุขภาพ 309 คน เป็นข้อมูลประกอบเท่านั้น

## 5. กติกาคะแนนสุขภาพที่ยืนยันแล้ว

ทุกข้อใช้ ไม่เคย = 0, บางครั้ง = 1, เป็นประจำ = 2 คะแนน แสงมี 10 ข้อต่อช่วง รวมสูงสุดช่วงละ 20 คะแนน เสียงและความร้อนยังเป็นชุดละ 10 ข้อแบบครั้งเดียว ไม่ขยายเป็นก่อน–หลังโดยไม่มี requirement

- `before_total` = ผลรวม 10 ข้อก่อนปฏิบัติงาน/เรียน
- `after_total` = ผลรวม 10 ข้อหลังปฏิบัติงาน/เรียน
- `delta` = `after_total - before_total` มีค่าได้ตั้งแต่ −20 ถึง +20
- ผลต่าง > 0: อาการเพิ่มขึ้น/เข้าเงื่อนไขเสี่ยงเพิ่มตามแบบประเมิน; = 0: ไม่เปลี่ยนแปลง; < 0: ลดลง
- ระดับ 3 ระดับอ้างคะแนนหลัง: 0–6 ระดับเดิมกลุ่มต่ำ/ปกติ, 7–13 ปานกลาง, 14–20 สูง
- ผลต่างไม่ใช้แทนคะแนนหลัง และไม่รวมคะแนนก่อน+หลังเป็นเต็ม 40 แล้วใช้เกณฑ์เต็ม 20
- ไม่ตีความผลต่าง ≤ 0 ว่าไม่มีอาการ เพราะคะแนนหลังอาจยังสูง
- ข้อมูลนี้เป็นผลแบบประเมินอาการ ไม่ใช้ข้อความที่สรุปว่าแสงเป็นสาเหตุทางการแพทย์ที่พิสูจน์แล้ว

ตารางสำหรับนำไปอธิบายลูกค้า (ตัวเลขสมมติสาธิตกติกา ไม่ใช่ข้อมูลผู้ตอบจริง):

| ก่อน | หลัง | ผลต่าง | การเปลี่ยนแปลง | ระดับตามคะแนนหลัง |
| ---: | ---: | ---: | --- | --- |
| 2 | 4 | +2 | อาการเพิ่มขึ้น | กลุ่มต่ำ/ปกติ |
| 6 | 8 | +2 | อาการเพิ่มขึ้น | ปานกลาง |
| 12 | 14 | +2 | อาการเพิ่มขึ้น | สูง |
| 8 | 8 | 0 | ไม่เปลี่ยนแปลง | ปานกลาง |
| 18 | 16 | −2 | อาการลดลง | สูง |
| 0 | 0 | 0 | ไม่เปลี่ยนแปลง | กลุ่มต่ำ/ปกติ |

ผลต่าง +2 จึงให้ระดับต่างกันได้ ขึ้นกับคะแนนหลัง ส่วนรายการอาการที่เพิ่ม/ลดต้องเปรียบเทียบรายข้อ ไม่อนุมานชื่ออาการจากผลรวม

## 6. Required ทั้งโปรเจกต์และข้อยกเว้นช่องเสริม

คำสั่งล่าสุด D07 ครอบคลุมทุกฟอร์มทั้งบน UI และ Worker โดยยกเว้นช่องหมายเหตุ ข้อเสนอแนะ ความคิดเห็นเพิ่มเติม และแผนผังตาม D17 ให้เป็น optional เว้นว่างได้โดยไม่ต้องเลือกหรือพิมพ์ว่าไม่มี ส่วนรายละเอียดที่จำเป็นตามคำตอบ เช่น ระบุแหล่งเสียงเมื่อเลือกอื่น ๆ หรือรายละเอียดโรคเมื่อเลือกว่ามีโรค ยังเป็น required ตามเงื่อนไข ไม่จัดเป็นหมายเหตุ optional ช่องค้นหา/ตัวกรอง/ปุ่มไม่ใช่ช่องแบบประเมิน และค่าที่ระบบคำนวณเองไม่ต้องให้ผู้ใช้กรอกซ้ำ

| กลุ่ม | กติกาที่ต้องจัดทำใน field matrix ก่อน coding |
| --- | --- |
| ข้อมูลบุคคล | ชื่อ เพศ อายุ น้ำหนัก ส่วนสูง ระดับการศึกษา สถานภาพ และคำตอบโรคประจำตัวที่แสดง ต้องครบ; รายละเอียดโรคเมื่อมีโรค |
| งาน/การเรียน | ประเภทผู้ตอบ หลักสูตรตาม catalog จริง อายุงานหรือชั้นปี 1–6 ชั่วโมง/วัน ชั่วโมง/สัปดาห์ |
| คำตอบสุขภาพ | ต้องตอบ 0/1/2 จริงทุกข้อ ห้าม default ไม่เคยแทนคำตอบว่าง; แสงต้องครบทั้ง 2 ช่วง |
| แหล่งเสียง | ต้องตอบอย่างชัดเจน; อื่น ๆ ต้องมีรายละเอียด; none เลือกพร้อมแหล่งอื่นไม่ได้ ตาม P0 spec |
| ตรวจสภาพแวดล้อม | metadata เดิมและใหม่ เทคนิค/ภาระงาน/ระยะเวลาที่สัมพันธ์กับวิธีวัด ค่าตรวจแต่ละจุด และช่องคำอธิบายที่แสดง ต้องครบ |
| ผังพื้นที่ | Optional ตาม D17; เลือก/ดูตัวอย่าง/เปลี่ยน/ลบไฟล์ในเครื่องก่อนทบทวนและยืนยันบันทึกแล้วจึง upload API; เพิ่มแผนผังภายหลังจากผลล่าสุดได้; รอบตรวจซ้ำใช้ผังที่ล็อกจากงานเดิมหรือไม่มีไฟล์ |
| ความพึงพอใจ | ข้อมูลผู้ประเมินและคะแนนครบ 16 ข้อต้องตอบ; ข้อเสนอแนะเป็น optional เว้นว่างได้ |
| เวลา 2 วิธี | ต้องกรอกทุกหน่วย ใช้ 0 สำหรับหน่วยที่ไม่มี; เก็บผลรวมเป็นวินาที และกำหนดว่าระยะเวลารวมต้องมากกว่า 0 |

ข้อมูลเก่าเปิดอ่านได้แม้ไม่มี field ใหม่ ก่อนตรวจซ้ำให้เติม metadata ที่ขาดครั้งเดียวพร้อมบันทึก supplement/audit ตาม D12 โดยไม่ rewrite snapshot เก่า ห้ามเติมค่าเดาหรือแก้ metadata ที่ผู้ใช้สั่งล็อกโดยเงียบ ๆ

## 7. ประเด็นมาตรฐานที่ต้องออกแบบให้ถูก

ข้อสังเกตต่อไปนี้มาจากไฟล์ที่ลูกค้าส่ง ไม่ใช่การรับรองว่าครอบคลุมกฎหมายทุกฉบับ:

- แสง: ตาราง 1 มีทั้งค่าเฉลี่ยของพื้นที่และค่าต่ำสุด แสดงว่าการเพิ่ม label Area อย่างเดียวแต่เก็บเลขเดียวไม่พอสำหรับการตรวจทั้งสองเงื่อนไข ส่วนตาราง 2 เป็นงานใช้สายตาเฉพาะจุด และตาราง 3 เป็นบริเวณรอบจุดทำงาน ต้องเลือกแถว/ขอบเขตที่ใช้ให้ชัด
- แสงแบบ Area ที่เสนอ: 1 พื้นที่มีหลายจุดย่อย คำนวณค่าเฉลี่ยและค่าต่ำสุดของพื้นที่นั้น เทียบทั้งสองเกณฑ์เมื่อมี; อย่าเฉลี่ยจุดต่างพื้นที่รวมกันเพื่อให้ผ่าน
- แสง Spot ที่เสนอ: เก็บ standard code และช่วง/คำอธิบายตามต้นฉบับ พร้อมกติกาว่าค่าใดเป็นเกณฑ์ตัดสิน ห้ามคิดว่า 400–500 แปลว่าเกิน 500 ไม่ผ่านโดยอัตโนมัติ
- เสียง: ตารางแนบท้ายมีระดับกับระยะเวลาหลายคู่ และหมายเหตุวิธีคำนวณเมื่อไม่มีค่าตรงตาราง ต้องจัดการการปัดค่าให้ตรงต้นฉบับ แยก `area average`, `exposure TWA`, และ `8-hour normalized TWA`; ห้ามใช้แทนกันหรือปรับด้วยเวลาซ้ำสองครั้ง
- ความร้อน: เอกสารมี WBGT และภาระงานเบา/ปานกลาง/หนัก เกณฑ์ที่ปรากฏ 34/32/30 °C; ทบทวนให้ตรงวิธีเก็บข้อมูลจริงและไม่ถือค่าเฉลี่ยอุณหภูมิทั่วไปเป็น WBGT
- ทุกผลต้องเก็บ standard version/ค่าที่ใช้ ณ เวลาตรวจ เพื่อเปิดรายงานเก่าแล้วไม่เปลี่ยนตาม catalog ปัจจุบัน
- คำแนะนำเดิมต้องคงอยู่และเพิ่มข้อความตามภาคผนวก B ส่วนข้อความที่ขัดกับสูตรใหม่ต้องตรวจแก้ความสอดคล้องใน P0/P5

## ภาคผนวก A เนื้อหาแบบประเมินใหม่

คำถามใช้ความหมายและลำดับตาม Word แก้คำผิดทางสะกดได้ แต่ไม่เปลี่ยนความหมายเอง เก็บ question ID พร้อม questionnaire version เพื่อไม่ปะปน q1–q10 รุ่นเก่า

### A1 แสง ก่อนและหลังใช้ชุดอาการเดียวกัน

ใช้คำนำตามช่วง เช่น “ก่อนปฏิบัติงาน/เรียนในบริเวณที่มีแสง … ท่านมีอาการ … หรือไม่” และ “หลังปฏิบัติงาน/เรียน …” รายละเอียดถ้อยคำบริเวณที่มีแสงให้สรุปเป็นฉบับเดียวใน P0

1. ปวดตา ปวดกระบอกตา หรือบริเวณรอบดวงตา
2. มีภาวะตาแห้ง
3. ระคายเคืองตา คันตา แสบตา
4. น้ำตาไหลบ่อย
5. ตาเบลอหรือมองเห็นไม่ชัด
6. ดวงตาไวต่อแสง ตาแดง
7. สายตาเปลี่ยนมากขึ้น
8. วิงเวียน
9. ปวดหัวไมเกรน
10. กล้ามเนื้อตากระตุก

เพิ่มคำถามแยก: “วันนี้ท่านปฏิบัติงาน/เรียนมาแล้วกี่ชั่วโมง” ไม่คิดรวมคะแนนอาการ ต้องกำหนดช่วงตัวเลข 0–24 และไม่รวมกับข้อมูลเวลาเฉลี่ยต่อวัน

### A2 เสียง

ก่อนคำถามอาการ: “ในขณะหรือหลังปฏิบัติงาน/เรียน ท่านสัมผัสเสียงดังจากแหล่งใดบ้าง (เลือกได้มากกว่า 1 ข้อ)” มี 8 ตัวเลือก:

1. เสียงประกาศตามสาย/ลำโพง
2. เสียงกิจกรรมหรือการจัดงานของวิทยาลัย
3. เสียงเครื่องปรับอากาศ/พัดลม
4. เสียงเครื่องมือหรืออุปกรณ์ในห้องปฏิบัติการ
5. เสียงเครื่องจักร เช่น เครื่องซักผ้า เครื่องถ่ายเอกสาร
6. เสียงจราจร ยานพาหนะ เช่น รถยนต์/รถจักรยานยนต์
7. เสียงก่อสร้างหรือซ่อมแซมอาคาร
8. เสียงอื่น ๆ โปรดระบุ

แหล่งเสียงเป็นข้อมูลประกอบ ไม่คิดคะแนน และไม่สร้างคำถามอาการ 10 ข้อซ้ำต่อแหล่งเสียง

หัวข้อตัวหนา: **จากแหล่งกำเนิดเสียงที่ท่านเลือก ท่านมีอาการอย่างไร**

1. ท่านมีอาการปวดหรือรู้สึกไม่สบายบริเวณหูหรือไม่
2. ท่านมีอาการหูอื้อหลังสัมผัสเสียงหรือไม่
3. ท่านมีอาการปวดศีรษะหลังสัมผัสเสียงหรือไม่
4. ท่านมีอาการเวียนศีรษะ หรืออาการมึนงงหรือไม่
5. ท่านรู้สึกว่าความสามารถในการได้ยินลดลงชั่วคราวหรือไม่
6. ท่านมีความยากลำบากในการฟังหรือสื่อสารกับผู้อื่นเนื่องจากเสียงหรือไม่
7. ท่านรู้สึกเหนื่อยล้าหรืออ่อนเพลียจากการอยู่ในบริเวณที่มีเสียงหรือไม่
8. ท่านรู้สึกเครียดหรือไม่สบายใจจากเสียงหรือไม่
9. ท่านมีอาการหงุดหงิดหรือรำคาญจากเสียงหรือไม่
10. สมาธิในการเรียนหรือการทำงานของท่านลดลงจากเสียงหรือไม่

### A3 ความร้อน

หัวข้อตัวหนา: **ขณะหรือหลังจากการปฏิบัติงาน/เรียนในบริเวณที่มีความร้อน ท่านมีอาการอย่างไร**

1. ท่านรู้สึกว่าร่างกายมีความร้อนกว่าปกติหรือไม่
2. ท่านมีอาการเหนื่อยล้า อ่อนเพลีย หรือกระหายน้ำหรือไม่
3. ท่านมีอาการปวดศีรษะ หรือรู้สึกอ่อนแรงหรือไม่
4. ท่านมีอาการวิงเวียนศีรษะ มึนงง หน้ามืดหรือไม่
5. ท่านรู้สึกเครียด หงุดหงิด หรือมีสมาธิในการปฏิบัติงาน/เรียนลดลงหรือไม่
6. ท่านรู้สึกวิตกกังวล สับสน หรือมีความสามารถในการปฏิบัติงานและทำกิจกรรมลดลงหรือไม่
7. ท่านรู้สึกว่าหัวใจเต้นเร็วหรือมีอาการสั่นหรือไม่
8. ท่านมีอาการเหงื่อออกมากผิดปกติ หรือรู้สึกคล้ายจะเป็นลมหรือไม่
9. ท่านมีอาการคลื่นไส้ หรืออาเจียนจากความร้อนหรือไม่
10. ท่านมีอาการปวดเกร็งกล้ามเนื้อหรือตะคริวหรือไม่
