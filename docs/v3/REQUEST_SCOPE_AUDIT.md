# ตรวจขอบเขตการเปลี่ยนแปลงตามคำสั่งเจ้าของงาน

16 ตุลาคม 2026 อ้างอิงคอมมิตเดิม c278e1e และคำยืนยัน D01–D47 ใน REQUIREMENTS_V3.md

คำสั่ง D48 มีผลเหนือแบบออกแบบที่ผู้พัฒนาเขียนเองใน P0 spec และ Field matrix แบบออกแบบดังกล่าวไม่ใช่หลักฐานว่าเจ้าของงานสั่งเพิ่มฟีเจอร์

## ส่วนที่คืนในรอบนี้

| ส่วน | คืนพฤติกรรม |
| --- | --- |
| ฟอร์มความร้อน | คืนสถานที่/แผนก เวลาเริ่ม/สิ้นสุด HH:MM ประเภทพื้นที่ DB/WB/GT WBGT จากเครื่อง ประเภทงาน มาตรฐาน WBGT เฉลี่ย และหมายเหตุ ตามชุดฟิลด์เดิม |
| วิธีกรอกความร้อน | เอาตัวเลือกวิธีรับค่าและปุ่มเพิ่ม/ลบช่วงวัดออกจาก UI ไม่บังคับทุกการตรวจให้เป็น 120 นาที |
| เงื่อนไขเวลาความร้อน D49 | เอาข้อบังคับเวลารายจุดต้องอยู่ภายในเวลารวมออกจากฟอร์ม/API ทั้งบันทึกใหม่ แก้ไข และวัดซ้ำ |
| ค่าความร้อน | เก็บ raw temperatures, ค่าเครื่อง, ค่าเฉลี่ยและมาตรฐานแยกกัน คืนการคำนวณอัตโนมัติจากอุณหภูมิและการรับค่าจากเครื่อง ตามโค้ดเดิม ค่าเฉลี่ยยังแก้เองได้ |
| ฟอร์มเสียง | เอาตัวเลือกวิธีประเมินเพิ่มเองและช่องเลือกระยะเวลาซ้ำออก ใช้ช่องต่ำสุด สูงสุด เฉลี่ย และระยะเวลาสัมผัสที่จำเป็นต่อ D13 |
| สรุปเสียง/ความร้อน | คืนค่าตรวจวัดเฉลี่ยรวมแบบเดิม แทนการเลือกค่าสูงสุดมาแสดง ผลผ่าน/ไม่ผ่านยังยึดผลแต่ละจุด |
| ค่าเป้าหมายมาตรฐานแสง D52 | เอาช่องตัวเลขเป้าหมายที่เพิ่มเองออก เลือกแถวใช้ขั้นต่ำอัตโนมัติ คงค่าประวัติเดิม และคืนคำอธิบายภาษาไทยท้ายตัวเลือก |

ข้อมูลที่เคยบันทึกแบบหลายช่วงยังเก็บครบใน snapshot และรายละเอียดประวัติ การคืนฟอร์มไม่ลบ/แปลงรอบเก่า การแก้เฉพาะข้อมูลทั่วไปหรือแนบผังส่งหน่วยตรวจเดิมกลับตามเดิม

## ส่วนที่คงไว้เพราะมีคำสั่งรองรับ

| ส่วน | ที่มา |
| --- | --- |
| สองกลุ่มหลัก กลุ่มละสี่เมนู และแยกความพึงพอใจ | R01, R20–R22, D34 |
| หลักสูตร ชั้นปี ข้อมูลผู้ตอบ และชั่วโมง | D03/D04/D09/D10, R03/R04/R07 |
| ชุดคำถามสุขภาพและแสงก่อน/หลัง | D01, R06–R11 |
| แสง Spot/Area และการคำนวณเสียงตามระยะเวลา | D08/D13, R13–R15; ไม่มีจุดย่อย Area ตาม D40 |
| ตรวจซ้ำและประวัติ ล็อกจุด/เกณฑ์ และ carry จุดผ่าน | D02/D11, R17–R19 |
| ข้อมูลผู้ตรวจ/ข้อมูลการตรวจแก้ได้แยกตามรอบวัดซ้ำ พร้อมชื่อในประวัติ | D54 แทนกติกาล็อก metadata เดิม |
| รายงานและ Excel แยกฟอร์ม/กลุ่ม ส่งออกประวัติ | R23, D35/D36 |
| UI รายงานเดิม ขนาดปุ่มและ breakpoint | D28–D33/D43/D44 |
| ยกเลิกเอกสารฝังหน้า ซ่อน UUID loading และจัดการผังในหน้าผล | D39/D42/D45–D47 |

การยกเลิกเหตุผลแก้ไข แยกปุ่มตรวจซ้ำซ้ำซ้อน และจุดย่อยแสง เป็นคำสั่งที่ทำไปแล้วตาม D25/D26/D40/D42 ไม่คืนสิ่งเหล่านี้เข้ามา

## ผลตรวจ

P5 browser 17 และ P7 browser 17 ผ่าน รวมฟอร์มความร้อนช่วง 45 นาที บันทึก DB=35/WB=28/GT=40, ค่าเครื่อง 31.2 และค่าเฉลี่ยที่แก้เป็น 31.3 แยกกัน เปิดแก้ไขกลับมาได้ครบ คงการ carry รอบตรวจเก่า และอ่าน/ส่งออกข้อมูลเก่าที่เคยบันทึกหลายช่วงได้ รวม typecheck frontend/Worker, scoped ESLint, domain 17 + migration 6 + P5 unit 12 + P7 unit 11 ผ่าน ยังไม่ deploy
