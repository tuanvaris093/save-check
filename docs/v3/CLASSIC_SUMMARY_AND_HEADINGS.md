# การ์ดสรุปแบบเดิมและรูปแบบหัวข้อ

15 ตุลาคม 2026 — D33

คืนดีไซน์การ์ดจาก `git show HEAD:src/app/dashboard/page.tsx` ตามภาพเจ้าของงาน: การ์ด KPI 4 ใบ ไอคอน/ตัวเลขแยกสี และวงกลมตกแต่งมุมล่าง แถวสรุปประเภทใช้ไอคอนสีและจำนวนชิดขวา

ข้อมูลทั้งหมดใช้ summary API ปัจจุบันตามตัวกรอง: จำนวนรวม/จำนวนแต่ละประเภท/ความพึงพอใจเฉลี่ย ไม่ย้อนความหมายสุขภาพเป็นผ่าน–ไม่ผ่าน เก็บรายละเอียด 6 หมวดและความพึงพอใจ 2 กลุ่ม × 4 ด้านครบ การ์ดสรุปยังอยู่เหนือ filter และไม่แก้ API หรือฐานข้อมูล

เอาขีดคั่นออกจากหัวข้อ Dashboard, ฟอร์มสภาพแวดล้อม, ฟอร์มสุขภาพ, สรุปสุขภาพ, สรุปความพึงพอใจ, review และชื่อหน้า ใช้ข้อความไทยต่อเนื่อง ข้อความรองคนละบรรทัด หรือวงเล็บสำหรับโหมดแทน รักษาขีดที่เป็นช่วงตัวเลข/เวลาและสัญลักษณ์ข้อมูลว่างไว้เพราะไม่ใช่หัวข้อ

แนวทางต่อไป: ไม่ใช้ `-`, `–`, `—` คั่นหัวข้อ UI ใช้ typography/ระยะห่าง/ไอคอนที่มีความหมายแทน ใช้ Lucide และ CSS เดิมของโปรเจ็กต์ ไม่เพิ่ม dependency
