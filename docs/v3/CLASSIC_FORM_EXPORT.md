# Export แยกตามแบบฟอร์มแบบเดิม

15 ตุลาคม 2026 — D35

อ้างอิงรูปแบบ `src/lib/excel-export.ts` เดิมและไฟล์ Excel/ภาพที่เจ้าของงานส่งมา คืนรายงานสำหรับอ่านข้อมูลเป็นแบบฟอร์มครบในชีตเดียว แทนการเริ่มจากตาราง normalized หลายชีต

## ชีตหลักและลำดับ

1. ภาพรวมทั้งหมด: หนึ่งแถวต่อรหัสงาน ผลล่าสุดในชุดข้อมูลที่ส่งออก
2. สิ่งแวดล้อม-แสงสว่าง
3. สิ่งแวดล้อม-เสียง
4. สิ่งแวดล้อม-ความร้อน
5. สุขภาพ-แสงสว่าง
6. สุขภาพ-เสียง
7. สุขภาพ-ความร้อน
8. ความพึงพอใจ-สภาพแวดล้อม
9. ความพึงพอใจ-อาการทางสุขภาพ

สร้างเฉพาะชีตฟอร์มที่มีข้อมูล ตามโค้ดเดิม จึงไม่เติมชีตฟอร์มเปล่าเมื่อดาวน์โหลดผลเดียวหรือกรองข้อมูล

## ข้อมูล

- ประเภทคือ assessment_group (สภาพแวดล้อม/อาการทางสุขภาพ) หมวดความพึงพอใจคือ general ไม่สลับกันหรือแก้ค่าที่จัดเก็บ
- สภาพแวดล้อมรวมผู้ตรวจ อุปกรณ์/serial/สอบเทียบ ผู้รับผิดชอบ วันเวลา ผัง จุดตรวจ หมายเหตุ ค่าจริง เกณฑ์/เอกสาร/รุ่นมาตรฐาน ผลที่บันทึก และแหล่งที่มาค่าตรวจเดิมในชีตหมวดนั้น
- Area: หนึ่งแถวต่อจุดย่อย โดยคงค่าเฉลี่ย/ค่าต่ำสุดและเกณฑ์พื้นที่; Heat แบบช่วงวัด: หนึ่งแถวต่อช่วงพร้อม WB/GT/DB/นาทีและ WBGT ที่บันทึก; วิธีจากเครื่องเก็บค่าที่กรอกโดยไม่สร้างช่วงวัดขึ้นเอง
- สุขภาพ: profile/workInfo ตามฟอร์ม คำตอบและข้อความที่บันทึกแต่ละข้ออยู่แนวนอน แสงมีคะแนน/คำตอบก่อนและหลัง/ผลต่าง ส่วนเสียง/ความร้อนมี single score; บริบทเฉพาะหมวดไม่ปนฟอร์มอื่น
- ความพึงพอใจแยกกลุ่ม ชื่อผู้ตอบ คะแนน 16 ข้อ/ข้อความจริง ค่าเฉลี่ย 4 ด้านและรวม ข้อเสนอแนะ; สุขภาพมีประเภทผู้ตอบ/หลักสูตร/ชั้นปี สภาพแวดล้อมมีเวลาที่ผู้ตอบกรอก ไม่เพิ่มช่องสุขภาพที่ฟอร์มไม่ได้ถาม
- ใช้ immutable snapshots และค่าผล/เกณฑ์ที่บันทึก ไม่ประเมินซ้ำตาม catalog ปัจจุบัน ไม่แทนข้อมูลว่างด้วยศูนย์
- วันที่เป็น Excel serial ที่แสดงเวลาไทย ตัวเลข/คะแนนเป็นตัวเลขจริง หัวคอลัมน์คำถามยาวขึ้นบรรทัดตาม grapheme เพื่อไม่ตัดเครื่องหมายสระ
- ตาราง source/audit เดิมรวม snapshot แบบแบ่งส่วนยังอยู่ในชีตซ่อนสำหรับตรวจสอบข้อมูลครบ ไม่ปนลำดับชีตหลัก
- การส่งออกจาก Dashboard ยังใช้ตัวกรองและผลล่าสุด ส่วนหน้าผลใช้รอบ/รุ่นที่เปิดอยู่ ไม่มีการเปลี่ยนฐานข้อมูลหรือ deploy

## ตรวจสอบ

- อ่านไฟล์ที่เจ้าของงานส่งและสร้างใหม่จาก snapshot ด้วย production builder; ตรวจรหัสครบและ snapshot หลังเขียน/อ่าน XLSX ตรงต้นฉบับทุกส่วน ไม่มี formula error
- ตรวจ render ชีตภาพรวม ค่าตรวจ และคอลัมน์คำถามจริงด้วย artifact-tool
- Unit ครอบคลุมรูปแบบชีตหลัก/hidden audit, ข้อความคำถามที่บันทึก, คะแนน/เกณฑ์, cell limit/ข้อมูลยาว, pagination/export guard
- Browser ครอบคลุมการดาวน์โหลดทุกฟอร์ม, ชีตหลักครบ 9 ชีตเมื่อมีข้อมูลครบ, แยกความพึงพอใจและฟิลด์เฉพาะกลุ่ม, Area/Heat แถวรายละเอียด, ก่อน/หลัง, ตัวกรองเดียวกับตาราง/KPI, export เกิน 100 งานและผลย้อนหลัง
- ผลสุดท้าย: unit 11 + P7 browser 15 ผ่าน; frontend typecheck, scoped ESLint และ diff check ผ่าน ไม่มี browser runtime error/FK violation
