# คืน UI ตัวกรองและตารางแบบเดิม

15 ตุลาคม 2026 — D32

อ้างอิงหน้าตาจาก component เดิมใน Git HEAD และภาพเจ้าของงาน โดยคืนเฉพาะการจัดวาง/รูปแบบ ไม่ย้อนข้อมูลหรือ requirement

- คืนช่องค้นหาพร้อมไอคอน แถวตัวเลือกกระชับ ปุ่มช่วงเวลา ทั้งหมด/วันนี้/7 วันล่าสุด/30 วันล่าสุด และช่องวันที่คู่ ปุ่มล้างเล็กอยู่ด้านขวา
- คงตัวกรองประเภท หมวดหมู่ กลุ่ม การเรียงลำดับ ฐานวันที่ และวันเริ่ม/สิ้นสุดเดิม ปุ่มช่วงเวลาใช้ค่า start/end ของ API เดิม
- คงคอลัมน์ปัจจุบันครบ 8 คอลัมน์: วันที่และเวลา, รหัสการประเมิน, ประเภท, หมวดหมู่, ผู้ตรวจ / ผู้ตอบ, ผลการประเมิน, แผนผัง, ดำเนินการ
- คืนแถวตารางบาง ป้ายประเภทสี ป้ายผลเส้นขอบ และปุ่มแบ่งหน้าแบบไอคอนเล็ก เพิ่มไปหน้าแรก/สุดท้ายโดยใช้ pagination เดิม
- การ์ดสถิติอยู่บนตัวกรองเหมือน requirement ปัจจุบัน Excel ยังส่งออกผลล่าสุดตามตัวกรอง และผลสุขภาพ/ความพึงพอใจยังใช้ความหมายปัจจุบัน
- ไม่แก้ backend/ฐานข้อมูล ไม่คืนฟังก์ชันคลังหรือรอประเมินหลัง และไม่ deploy

## การตรวจสอบ

- `npm run test:p7:browser`: ผ่าน 15 scenarios รวมการกรอง/Excel/ประวัติ/แบ่งหน้าแรก–สุดท้าย และ responsive matrix 6 ขนาด × 4 routes
- เพิ่มตรวจปุ่มวันนี้/ทั้งหมดโดยไม่ล้างตัวกรองกลุ่ม และตรวจหัวตารางครบ 8 คอลัมน์
- ตรวจปุ่มล้าง/แบ่งหน้าและช่องวันที่ที่ 320/390/1440px: ไม่มี document overflow
- `npm run typecheck`, ESLint เฉพาะไฟล์ที่แก้ และ `git diff --check` ผ่าน
