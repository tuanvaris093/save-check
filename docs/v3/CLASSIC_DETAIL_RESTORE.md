# คืนรูปแบบหน้ารายละเอียด

คำยืนยัน D43 วันที่ 16 ตุลาคม 2026 ใช้ภาพอ้างอิงและโค้ดหน้าผลในคอมมิต c278e1e เป็นฐาน เว็บ production ไม่สามารถอ่านผ่านเครื่องมือเว็บได้ในรอบนี้

- คืนหัวข้อพร้อมป้ายประเภท ข้อมูลทั่วไปแบบสองคอลัมน์ แถบผลสีเขียว/แดง ไอคอนวงกลม และกล่องค่าตรวจวัดด้านข้าง
- ตารางกลับมาใช้เส้นคั่นแถวบาง ค่าตัวเลขตัวหนา และป้ายผลทรงแคปซูล ใช้ร่วมกันในหน้ารายละเอียดและทบทวนสิ่งแวดล้อม ส่วนตารางรายงานอื่นใช้เส้นคั่นแบบเดียวกัน
- คงข้อมูลใหม่ครบ: ค่าต่ำสุด/ค่ารอบบริเวณจุดตรวจ เกณฑ์จริง วันเวลาวัดจริง ที่มาของผลที่คงจากรอบก่อน ช่วง WBGT และข้อมูลเครื่องมือ/การปรับเทียบ/ผู้รับผิดชอบ
- แสดงค่าเฉลี่ยแสงจากค่าที่บันทึก สำหรับ Area ระบุว่าเป็นค่าเฉลี่ยของพื้นที่ตรวจวัด ส่วนเสียงแสดงค่าประเมินสูงสุด และความร้อนแสดง WBGT สูงสุด ป้ายผ่าน/ไม่ผ่านยังมาจากผล revision จริง ไม่ใช้ตัวเลขรวมตัดสินแทนผลแต่ละจุด
- วางผังห้องหลังตารางตามแบบเดิม เปิดและดาวน์โหลดได้ คงการเลือกไฟล์และประวัติของรอบไว้
- ตัวโหลดกลางเหลือวงหมุนกับข้อความกำลังโหลด ไม่มีพื้นกล่อง กรอบ หรือเงา คงตัวกันส่งซ้ำและการรอหลายคำขอ

การตรวจ: typecheck และ scoped ESLint ผ่าน; ตรวจภาพมือถือทั้งหน้ารายละเอียดและ loading และใช้ชุด P5/P7 browser ตรวจฟอร์ม รายงาน ประวัติ การส่งออก และ responsive โดยฐานทดสอบแยก ยังไม่ deploy

ผลสุดท้าย P5 browser 16 / P7 browser 17 ผ่าน รวมเทียบตัวเลขสรุปกับ revision ทุกหมวดและตรวจพื้นโปร่งใส ไม่มีเงา/กรอบของตัวโหลด ตรวจภาพมือถือและจอ 1280px แล้ว
