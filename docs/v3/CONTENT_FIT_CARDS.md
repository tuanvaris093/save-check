# การ์ดเลือกแบบประเมินสูงตามเนื้อหา (D31)

วันที่: 15 ตุลาคม 2026 · ยังไม่ deploy

สาเหตุ: category-card และ assessment-menu-card มี min-height 116px ทำให้เกิดพื้นที่ว่างแม้ข้อความสั้น นอกจากนี้ grid stretch อาจยืดการ์ดที่สั้นตามอีกใบในแถวเดียวกัน

- เอา min-height 116px ออก ใช้ height:auto และ padding 16px บน–ล่างเท่ากัน
- ใช้ align-items:start ใน grid ให้แต่ละใบสูงตามเนื้อหา แต่ home grid แบบ flex-column ยัง stretch ความกว้างเต็มแถวตามเดิม
- ใช้ content-cards.css ที่ layout เพื่อให้กฎขนาดมีผลกับหน้าใช้งานจริง ไม่ถูกกฎ min-height เก่าทับ
- ครอบคลุมหน้าเลือกสภาพแวดล้อม/สุขภาพ รวมความพึงพอใจ และการ์ดเลือกประเภทบนหน้าแรก คงสีไอคอนและ breakpoint 1440px
- วัด localhost:3001 จริง การ์ดข้อความสั้นสูงประมาณ 85.22px, เนื้อหา 51.98px ส่วนที่เหลือเป็น padding 16px ต่อด้านกับขอบเท่านั้น ไม่เหลือขั้นต่ำ 116px

ตรวจ frontend typecheck/ESLint/diff check ผ่าน; P7 browser 15 scenarios ผ่าน รวม assertions ใหม่ที่วัดความสูงการ์ดเท่ากับเนื้อหา + padding + border ที่ 390/820/1024/1366/1439/1440px ทั้งสองกลุ่ม
