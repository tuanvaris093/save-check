# สองประเภทหลักและความพึงพอใจภายในประเภท

15 ตุลาคม 2026 — D34

ตัวกรองประเภทมีเฉพาะ สภาพแวดล้อม และอาการทางสุขภาพ (พร้อมทุกประเภท) ความพึงพอใจเป็นหมวดภายในแต่ละประเภท เอาตัวกรองกลุ่มที่ซ้ำออก

แก้การส่ง query จาก dropdown ให้ใช้ `group=environment|health` แทน raw `type` ของรูปแบบการบันทึก ใช้ params ชุดเดียวสำหรับ summary/list/export การเลือกหมวดความพึงพอใจเพิ่ม `category=general` จึงได้ความพึงพอใจของประเภทที่เลือกเท่านั้น Backend มีเงื่อนไข assessment_group แบบ parameter binding อยู่แล้ว ไม่ต้องเปลี่ยน schema หรือแปลงข้อมูลเก่า และยังรองรับ raw type สำหรับงานภายในเดิม

ยอด KPI และแถวสรุปประเภทใช้ by_group รวมความพึงพอใจของประเภทนั้น เพิ่มหมวดความพึงพอใจในแต่ละแถว คง 6 หมวดตรวจวัด/สุขภาพและคะแนนความพึงพอใจ 2 กลุ่ม × 4 ด้านไว้ทั้งหมด ตารางแสดงประเภทจาก assessment_group และหมวดความพึงพอใจจาก general คงคอลัมน์เดิมครบ Excel ยังคง metadata ประเภทแบบฟอร์มที่จัดเก็บสำหรับตรวจสอบ แต่ชุดข้อมูลที่ส่งออกกรองตามประเภทหลักตรงกับหน้าเว็บ

## ตรวจสอบ

- P7 browser ตรวจ dropdown มีเฉพาะ all/environment/health ไม่มี dropdown กลุ่มซ้ำ
- เลือกแต่ละประเภทเทียบ API group query: รวมทั้งแบบประเมินและความพึงพอใจ เฉพาะกลุ่มที่ถูกต้อง จำนวนตรง KPI/ตาราง/Excel
- เลือกสุขภาพ + หมวดความพึงพอใจได้เฉพาะแบบสอบถามสุขภาพ และ bulk export/หน้าแรก–สุดท้ายยังทำงาน
- P7 browser ผ่าน 15 scenarios, typecheck ผ่าน, ESLint ไม่มี error (warning เดิม api.ts 13 จุด), diff check ผ่าน
- ไม่ deploy หรือแก้ข้อมูลฐานข้อมูล
