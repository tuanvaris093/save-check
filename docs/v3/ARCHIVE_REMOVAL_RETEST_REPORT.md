# ยกเลิกเก็บเข้าคลัง และคงประวัติวัดซ้ำ (D24)

วันที่: 15 ตุลาคม 2026 · ยังไม่ deploy

## ข้อกำหนดล่าสุด

เจ้าของงานให้เอาปุ่มและฟังก์ชันเก็บเข้าคลังออก ข้อมูลบันทึกตามปกติ ประเมินวัดซ้ำได้ และเก็บผลแต่ละรอบพร้อมวันเวลาสำหรับเปิดดูย้อนหลัง

## การปรับ

- เอาปุ่มเก็บ/คืนคลัง แบบฟอร์มเหตุผล และตัวกรองสถานะคลังออกจากหน้าผลและ Dashboard
- ยกเลิก client/service สำหรับเก็บเข้าคลัง; POST archive/restore และ DELETE เดิมตอบ 410 โดยไม่เปลี่ยนข้อมูล
- รายการ/สถิติ/Excel ไม่ซ่อนข้อมูลจาก archive flag เก่า และ flag เก่าไม่ปิดกั้นการเปิดฟอร์ม/แก้ไข/วัดซ้ำ
- ไม่ลบผลเก่า ไม่แก้ค่าตรวจเดิม และคง audit history เดิม
- Migration 0007 เปลี่ยนเฉพาะ revision_parent_guard เพื่อเลิกตรวจ archive flag; คงการตรวจเจ้าของรอบ ฐานล่าสุด เลขรอบต่อเนื่อง และรอบที่ finalize แล้ว รวมทั้ง immutable/concurrency guard อื่น

## พฤติกรรมประเมินวัดซ้ำที่คงไว้

- เปิดผลล่าสุดแล้ววัดซ้ำเฉพาะจุด/พื้นที่ไม่ผ่าน โดยข้อมูลสถานที่ เครื่องมือ และมาตรฐานถูกล็อกตาม requirement
- ปุ่มประเมินวัดซ้ำ/แก้ไขทั่วไปยังใช้ flow ที่สร้าง revision ใหม่; D25 ยกเลิกการกรอกเหตุผลด้วยตนเอง ใช้ชื่อการดำเนินการสำหรับ audit อัตโนมัติ
- บันทึกจะเพิ่มรอบใหม่ ไม่เขียนทับรอบเก่า จุดที่ไม่ได้วัดใหม่คงผลพร้อมวันเวลาวัดจริงของรอบเดิม
- หน้า “ประวัติรอบตรวจ” แสดงจำนวนรอบ เลขรอบ ชนิดการดำเนินการ วันเวลา และกดเปิดผล/Excel/PDF ของรอบนั้นได้

## หลักฐาน

- P2 API 23 scenarios ผ่าน รวม failed-only retest 3 รอบ/ประวัติ/เวลาแต่ละจุด/immutable/concurrency และ API คลังที่เลิกใช้งาน
- P5 browser 16 scenarios ผ่าน รวมไม่ผ่าน → ไม่ผ่าน → ผ่าน ตรวจเฉพาะจุดไม่ผ่าน การล็อกข้อมูล และแก้ไขแบบสร้าง revision
- P7 browser 14 scenarios ผ่าน รวมทดสอบ flag คลังเก่ากับการเปิดฟอร์มและบันทึกวัดซ้ำจริง
- Frontend/Worker typecheck ผ่าน; lint 0 errors / 74 warnings เดิม
- สำรองฐาน local ก่อน apply 0007; ข้อมูล 25 ตารางเดิม hash ตรงครบ, foreign key violations 0 ดู baseline/retire-archive-local-backup.json และ baseline/retire-archive-local-verify.json
- ฐาน local ไม่มีรายการที่เก็บคลัง ณ ก่อน migration จึงไม่มีรายการต้องเปลี่ยนสถานะ ไม่มี remote migration/deploy


## D25: ไม่ต้องกรอกเหตุผล (15 ตุลาคม)

- เอาช่องเหตุผลและข้อความเหตุผลใน preview ของ environment correction/supplement ออก ยกเลิก validation ที่กั้นขั้นตอน/ส่งเพราะไม่มีเหตุผล
- Client ไม่ส่ง reason จากร่างเดิม; shared contract ยอมให้ environment correction ละ reason ได้ โดยระบบใช้ “ประเมินวัดซ้ำ” เป็นชื่อการดำเนินการใน audit และ supplement ใช้ “เติมข้อมูลประกอบสำหรับการตรวจวัด”
- ไม่เปลี่ยนชนิด revision/มาตรฐาน/จุดที่ล็อก/การคงประวัติ และไม่แก้เหตุผลที่บันทึกในรอบเก่า
- P5 browser 16 scenarios ผ่าน รวมเข้าวัดซ้ำ/แก้ไขค่าตรวจและข้อมูลโดยไม่มีช่องเหตุผล แล้วบันทึกพร้อมเปิด snapshot เก่าและ audit ได้; frontend/Worker typecheck และ ESLint ไม่มี errors
- ปรับ migration regression ที่เคยคาดว่า archive flag ต้องปิดกั้นรอบใหม่ ให้ตรง D24 ที่ยกเลิกคลัง โดยคงการทดสอบ immutable/concurrency/parent guard
- ไม่มี migration ใหม่ใน D25 และยังไม่ deploy
