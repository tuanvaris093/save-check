# ตรวจ UI ทุกหน้ากับรูปแบบเดิม

วันที่: 14 ตุลาคม 2026 · สถานะ: done · ยังไม่ deploy

เทียบกับ UI ใน Git HEAD `c278e1e` และคำยืนยันล่าสุด D17–D20 ของเจ้าของงาน ใช้ข้อมูล คำถาม คะแนน และกติกาปัจจุบัน งานนี้ไม่ย้อนกลับ schema หรือแสดงข้อมูลชุดเก่า

## ผลตรวจแยกหน้า

| หน้า / ส่วน | ผลเทียบและการปรับ |
| --- | --- |
| หน้าแรก `/` | Hero, เมนู, คำอธิบาย, footer, ข้อมูลผู้จัดทำ/ลิขสิทธิ์ยังอยู่; คงสองกลุ่มตาม requirement และความพึงพอใจอยู่ในแต่ละกลุ่ม |
| เมนูสภาพแวดล้อม / สุขภาพ | Header/ย้อนกลับ/การ์ด 4 หมวดของแต่ละกลุ่มยังอยู่ ใช้ชื่ออาการทางสุขภาพปัจจุบัน |
| ฟอร์มสภาพแวดล้อม ทั้งแสง/เสียง/ความร้อน | คืนหัวข้อ “ข้อมูลการตรวจ” และ “แบบฟอร์มบันทึกการตรวจวัด”; คืนกรอบฟอร์ม/ตำแหน่ง header แบบเดิม; แผนผัง optional, preview/review ก่อน API และเพิ่มภายหลังยังใช้ตาม D17 |
| ฟอร์มสุขภาพ ทั้งสามหมวด | คืนการ์ดและหัวข้อแยก “ข้อมูลส่วนตัว” / “ข้อมูลสุขภาพ” / “ข้อมูลการปฏิบัติงาน / การเรียน”; แก้ label ไม่มีโรคประจำตัวที่เผลอใช้ข้อความแหล่งเสียง; เก็บข้อคำถามปัจจุบันและก่อน/หลังของแสง |
| ความพึงพอใจ สองกลุ่ม | คืนกรอบฟอร์ม/ตำแหน่ง header แบบเดิม; ข้อมูลผู้ประเมิน หัวข้อ 4 ด้าน คำชี้แจงคะแนน และข้อเสนอแนะ optional ยังอยู่; เวลาที่กรอกเองใช้เฉพาะกลุ่มสภาพแวดล้อมตาม requirement |
| ทบทวน / ผลสภาพแวดล้อม | คืนหัวข้อผังพื้นที่ห้องทั้งกรณีแนบแล้ว/ยังไม่แนบ และหัวข้อคำแนะนำ; ตาราง ค่าที่ตรวจ และเกณฑ์เป็นข้อมูลปัจจุบัน |
| ข้อความลิงก์ตามภาพล่าสุด | เปลี่ยนข้อความ “แก้ไขข้อมูลพร้อมเหตุผล” เป็น “ประเมินวัดซ้ำ” ตามคำสั่งเจ้าของงาน; การเปลี่ยนนี้เป็นข้อความแสดงผลของลิงก์เดิม |
| ทบทวน / ผลสุขภาพ | คืนหัวข้อข้อมูลส่วนตัว/การปฏิบัติงาน สรุปผล รายละเอียดคำตอบ 10 ข้อ และข้อเสนอแนะเดิม; ข้อเสนอแนะอิงระดับอาการปัจจุบัน (แสงใช้ระดับจากคะแนนหลัง ไม่ใช้ผลต่างและไม่เรียกว่าผ่านมาตรฐาน) |
| ทบทวน / ผลความพึงพอใจ | คืนสรุปคะแนน 4 ด้านแบบการ์ดและหัวข้อรายละเอียดคำตอบ 16 ข้อ; คำถามมาจาก Word ปัจจุบัน แยกสองกลุ่ม ไม่แสดงชุดเก่า |
| Dashboard | คืนไอคอน header, “แยกตามประเภท” และ “ประวัติการประเมิน”; คงตาราง row/column และสถิติ 6 หมวด + ความพึงพอใจ 2 กลุ่ม × 4 ด้าน ไม่มี unknown/ตัวกรองรุ่น |
| ผลที่ไม่มีรหัส / โหลดไม่สำเร็จ | คืนหัวข้อข้อผิดพลาด พร้อมลองใหม่และกลับ Dashboard |
| `/complete` / 404 | หัวข้อ ไอคอน ข้อความ และปุ่มกลับยังอยู่ตามเดิม |
| Header / navbar / print | Header ยาวขึ้นบรรทัดได้ ไม่ตัดชื่อหมวด/รหัส; คงหัวข้อและรหัสผลหนึ่งชุด; navbar ที่ขอบ viewport และ print ซ่อน navigation |

## การทดสอบ

คำสั่งหลัก: `npm run test:ui-restore:regression -- audit`

Regression ใช้ Chromium กับ Worker/D1/R2 แยกจากข้อมูล development และพอร์ต 3074/3075 ทดสอบทั้ง mobile 390×844 และ desktop 1440×1000; ตรวจหน้าแรก, Dashboard, เมนู, แบบฟอร์มทั้งสามหมวด, ความพึงพอใจสองกลุ่ม, กลุ่ม/หมวดผิด, ผลไม่มีรหัส/ไม่พบงาน, complete และ 404 รวมถึงขั้นตอนทบทวน ผลลัพธ์ Excel PDF การอัปโหลดและตรวจซ้ำ

เพิ่ม assertions สำหรับหัวข้อที่คืนมา, ข้อความตัวเลือกโรค, Area ไม่มีคำอธิบาย Lux ยาว, สรุป 4 ด้าน/คำถาม 16 ข้อ, และข้อเสนอแนะสุขภาพครบ 3 หมวด × 3 ระดับ โดยเทียบข้อความเดิมครบทุกข้อและตรวจ snapshot ก่อน/หลังเปิดผลว่าไม่ถูกแก้

ผล: ผ่าน **150 scenarios/checks และ 13 commands** รวม typecheck frontend/Worker, lint (0 errors / 74 warnings เดิม), build (14/14) และ `git diff --check`

ระหว่างรันทดสอบ แก้ข้อคาดหวังของชุดทดสอบเดิมที่ยังเปิด legacy/คำถามเก่าให้ตรง D20, เปลี่ยนการทดสอบ forged retest ไปใช้ข้อมูลปัจจุบัน, รอข้อความ error จริงแทน placeholder ของ Next.js announcer และเพิ่มเวลา navigation ของชุด Word browser เป็น 60 วินาทีเพื่อรองรับ dev compile; รันชุดที่ล้มเหลวใหม่จนผ่านครบ เก็บ log ของรอบก่อนในโฟลเดอร์ ui-audit-logs งานนี้ไม่ได้ผ่อน validation หรือเปลี่ยนการคำนวณ/คำถามบน Worker

ฐาน development และเซิร์ฟเวอร์ของเจ้าของงานไม่ได้ถูกเปลี่ยนจากการทดสอบ เซิร์ฟเวอร์ทดสอบปิดแล้วหลังจบชุด ไม่มี schema migration, remote DB/R2 write, commit หรือ PR ในงานนี้ P9 ยังไม่เริ่ม

Firefox/WebKit/Safari/iOS และเครื่องพิมพ์จริงยังไม่ได้ทดสอบ ไม่ส่งข้อมูลไป Cloudflare และไม่ deploy/remote migration

## แก้ชื่อช่องเพิ่มเติมหลังจบ audit

เจ้าของงานยืนยันให้ใช้ “หลักสูตร / แผนก / ฝ่าย” โดยแทนเฉพาะคำว่า “คณะ” และรักษาส่วนแผนก/ฝ่ายไว้ ปรับชื่อช่องในฟอร์มสุขภาพ/ความพึงพอใจ ฟอร์มเดิมที่ใช้ร่วมกัน ผลสรุป ข้อความ validation และหัวคอลัมน์ Excel; คงรหัสข้อมูลและตัวเลือกหลักสูตร 7 รายการเดิม ตรวจ lint เฉพาะไฟล์ที่แก้ (0 errors / 6 warnings เดิม) และ `test:p6` ผ่าน 7 checks รวมชื่อคอลัมน์ใหม่กับค่าหลักสูตรเดิม งานแก้ wording นี้เกิดหลัง regression 150 checks ข้างต้นและยังไม่ deploy
