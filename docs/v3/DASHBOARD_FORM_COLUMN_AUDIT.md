# D56 — คอลัมน์ Excel สำหรับผู้ใช้ Dashboard

16 ตุลาคม 2026

ส่งออก Dashboard (`latest`) เป็นชีตภาพรวม และชีตตามประเภท/หมวดที่มีข้อมูลเท่านั้น ไม่แนบชีตข้อมูลระบบที่ซ่อนไว้ การส่งออกประวัติยังอ่าน snapshot แยกทุกรอบตาม D55

ทุกชีตเริ่มด้วย **ลำดับ / รหัสการประเมิน / วันที่และเวลา** วันที่หลักใช้เวลาสร้างรายการตรงกับ Dashboard ส่วนวันที่ตรวจ เวลาเริ่ม–สิ้นสุด และวันเวลาบันทึกแสดงแยกตามความหมาย

## ตรวจเทียบกับฟอร์ม

| ฟอร์ม | ช่องกรอกที่อยู่ใน Excel |
| --- | --- |
| สภาพแวดล้อมทุกหมวด | ผู้ตรวจ ตำแหน่ง สถานที่ วันที่ตรวจ เวลาเริ่ม/สิ้นสุด เครื่องมือ Serial วันที่สอบเทียบ แผนก ผู้รับผิดชอบ ชื่อไฟล์ผัง สถานที่/ลักษณะงานของแต่ละจุด หมายเหตุ |
| แสงเฉพาะจุด | เทคนิค มาตรฐานที่เลือกพร้อมช่วงค่าและคำอธิบาย ค่าตรวจ Lux ค่าบริเวณใกล้/ถัดออกไปเมื่อมี |
| แสงเฉลี่ยพื้นที่ | มาตรฐานที่เลือก ค่าเฉลี่ยพื้นที่ ค่าต่ำสุดพื้นที่ พร้อมเกณฑ์ของแต่ละค่า |
| เสียง | ค่าต่ำสุด/สูงสุด ค่าเฉลี่ย ระยะเวลาสัมผัส และ TWA8 เมื่อเป็นข้อมูลที่บันทึกในรูปแบบนั้น |
| ความร้อน | เวลาเริ่ม/สิ้นสุดรายจุด ประเภทพื้นที่ ประเภทงาน DB/WB/GT ค่า WBGT จากเครื่อง ค่าเฉลี่ย WBGT และค่ามาตรฐาน ข้อมูลเก่าที่วัดหลายช่วงยังคงค่ารายช่วง |
| สุขภาพทุกหมวด | ชื่อ เพศ อายุ น้ำหนัก ส่วนสูง สถานภาพ การศึกษา โรคประจำตัวและรายละเอียด ประเภทผู้ตอบ บริบท หลักสูตร/แผนก/ฝ่าย ชั้นปีหรืออายุงาน ชั่วโมงต่อวันและต่อสัปดาห์ คำตอบทุกข้อ |
| สุขภาพแสง | ชั่วโมงที่ทำงาน/เรียนวันนี้ คำตอบก่อนและหลังแยกทุกข้อ คะแนนก่อน/หลัง ผลต่าง และระดับอาการ |
| สุขภาพเสียง | แหล่งเสียงที่เลือกทั้งหมดและรายละเอียดเสียงอื่น คำตอบทุกข้อ คะแนนและระดับอาการ |
| สุขภาพความร้อน | คำตอบทุกข้อ คะแนนและระดับอาการ |
| ความพึงพอใจสภาพแวดล้อม | ชื่อ คำตอบ 16 ข้อ ข้อเสนอแนะ เวลาวิธีเดิม/SafeCheck แยกวัน ชั่วโมง นาที วินาที |
| ความพึงพอใจสุขภาพ | ชื่อ ประเภทผู้ตอบ บริบท หลักสูตร/แผนก/ฝ่าย ชั้นปี คำตอบ 16 ข้อ ข้อเสนอแนะ |

คงข้อมูลที่มีประโยชน์ต่อการใช้รายงาน: ผลผ่าน/ไม่ผ่าน เกณฑ์ตัวเลขและหน่วย คะแนนรวม/เฉลี่ยรายด้าน ผลต่างเวลา เลขครั้งที่บันทึก วันที่วัดจริงและคำอธิบายว่าคงค่าจากรอบก่อน รวมทั้งสถานะการแนบผัง

เอาออกจากไฟล์ Dashboard: รหัสไฟล์ รหัสรอบ/รอบฐาน รหัสจุด รหัสเกณฑ์ รุ่นมาตรฐาน/คำถาม/การประเมินผล รหัสรอบต้นทาง แหล่งเวลาภายใน ค่าเป้าหมาย Lux ที่ระบบกำหนด คอลัมน์ WBGT ซ้ำ ชื่อเอกสารมาตรฐานภายใน และชีต JSON/ตารางระบบทั้งหมด แสดงชื่อไฟล์ผังแทน UUID และคำอธิบายมาตรฐานที่เลือกแทน code โดยไม่เปลี่ยนผลหรือเกณฑ์ประวัติ
